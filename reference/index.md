# Package index

## Simulation of Lefkovitch MPMs

Functions for simulating Lefkovitch matrix models.

- [`rand_lefko_mpm()`](https://jonesor.github.io/mpmsim/reference/rand_lefko_mpm.md)
  : Generate random Lefkovitch matrix population models (MPMs) based on
  life history archetypes
- [`rand_lefko_set()`](https://jonesor.github.io/mpmsim/reference/rand_lefko_set.md)
  : Generate lists of Lefkovitch matrix population models (MPMs) based
  on life history archetypes

## Simulation of Leslie MPMs

Functions for simulating Leslie matrix models.

- [`make_leslie_mpm()`](https://jonesor.github.io/mpmsim/reference/make_leslie_mpm.md)
  : Create a Leslie matrix population model
- [`rand_leslie_set()`](https://jonesor.github.io/mpmsim/reference/rand_leslie_set.md)
  : Generate a set of random Leslie Matrix Population Models
- [`reorganise_matrices()`](https://jonesor.github.io/mpmsim/reference/reorganise_matrices.md)
  : Reorganise Matrix Population Models

## Model demographic trajectories

Functions for modelling demographic trajectories.

- [`model_fecundity()`](https://jonesor.github.io/mpmsim/reference/model_fecundity.md)
  [`model_reproduction()`](https://jonesor.github.io/mpmsim/reference/model_fecundity.md)
  [`model_fertility()`](https://jonesor.github.io/mpmsim/reference/model_fecundity.md)
  : Model reproductive output with age using set functional forms
- [`model_survival()`](https://jonesor.github.io/mpmsim/reference/model_survival.md)
  [`model_mortality()`](https://jonesor.github.io/mpmsim/reference/model_survival.md)
  : Model mortality hazard, survivorship and age-specific survival
  probability using a mortality model

## Understanding error

Functions for calculating and propagating error.

- [`add_mpm_error()`](https://jonesor.github.io/mpmsim/reference/add_mpm_error.md)
  : Add sampling error to matrix population models (MPMs) based on
  expected values of transition rates and sample sizes
- [`calculate_errors()`](https://jonesor.github.io/mpmsim/reference/calculate_errors.md)
  : Calculate error (standard error or 95%CI) in elements of a matrix
  population model.
- [`compute_ci()`](https://jonesor.github.io/mpmsim/reference/compute_ci.md)
  : Compute 95% confidence intervals for derived estimates from a matrix
  population model
- [`compute_ci_U()`](https://jonesor.github.io/mpmsim/reference/compute_ci_U.md)
  : Compute 95% confidence intervals for derived estimates from the U
  submatrix of a matrix population model

## Drivers of dynamics

Functions for simulating drivers of dynamics.

- [`driven_vital_rate()`](https://jonesor.github.io/mpmsim/reference/driven_vital_rate.md)
  : Calculate driven vital rates

## Utilities

Utility functions.

  : Summarise Matrix Population Models
